# Community Health

This is the personal-account default community-health repository for
`frasermolyneux`.

Repositories without local overrides inherit:

- issue forms from `.github/ISSUE_TEMPLATE/`;
- the pull-request template from `.github/PULL_REQUEST_TEMPLATE.md`.

This repository uses concise local Copilot guidance from
`.github/copilot-instructions.md`.

Keep inherited content short, technology-neutral, and broadly applicable.

The [lightweight engineering standards](docs/standards.md) summarize practical
development, testing, deployment, security, documentation, and observability
approaches already used across the current repositories.
